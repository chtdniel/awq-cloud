Privacy Policy

Terakhir diperbarui: 20 September 2026 · Berlaku untuk https://christiandaniel.my.id

AWQ Cloud Briefing adalah aplikasi kerja (workspace) untuk operasi briefing penerbangan: flight watch, NOTAM, TAF, cuaca, FIR, dan pembuatan crew briefing report. Halaman ini menjelaskan data apa yang diproses aplikasi, termasuk data akun Google ketika Anda membuat laporan dalam bentuk Google Sheets.

Ringkasan singkat. Aplikasi hanya meminta satu izin Google: https://www.googleapis.com/auth/drive.file. Izin ini hanya memberi akses ke file yang dibuat atau dibuka oleh aplikasi ini — bukan seluruh isi Google Drive Anda. Token akses Google hanya dipakai di browser Anda untuk proses unggah saat itu dan tidak pernah disimpan di server kami. Kami tidak menjual dan tidak membagikan data Anda untuk periklanan.

1. Data Google yang kami akses

Saat Anda menekan tombol untuk membuat laporan Google Sheets, aplikasi meminta persetujuan Anda melalui layar consent Google untuk satu scope saja:

ScopeApa yang diberikanYang tidak diberikan
drive.file Membuat file baru di Google Drive Anda dan mengubah file yang Anda buka atau bagikan lewat aplikasi ini. Tidak memberi akses ke file lain di Drive Anda, tidak membaca isi Drive Anda secara umum, tidak menghapus file di luar yang dibuat aplikasi ini.

Kami tidak meminta akses ke Gmail, Kontak, Kalender, atau data Google lain, dan tidak meminta scope Drive yang lebih luas.

2. Bagaimana data Google digunakan

  • Tujuan tunggal: membuat satu file spreadsheet crew briefing report atas permintaan Anda, di Google Drive milik akun Google yang Anda pilih sendiri, lalu membuka URL file tersebut di browser Anda.
  • Isi laporan berasal dari data yang sudah ada di dalam aplikasi (penerbangan, NOTAM, TAF, cuaca yang Anda pilih). Google tidak dipakai untuk menganalisis data Anda.
  • Kami tidak memakai data Google untuk iklan, profiling, penilaian kredit, atau keperluan apa pun di luar pembuatan laporan yang Anda minta.

3. Penyimpanan token dan data Google

  • Token akses Google diberikan langsung oleh Google ke browser Anda. Token itu dipakai hanya untuk proses unggah pada saat itu.
  • Token tidak disimpan di server aplikasi kami, tidak disimpan di localStorage, dan tidak dikirim ke backend aplikasi kami.
  • Kami tidak menyimpan salinan file Google Sheets atau isi Google Drive Anda di server kami. File tetap berada di Drive Anda dan tetap milik Anda.
  • Saat Anda menutup atau memuat ulang halaman, aplikasi akan meminta persetujuan Google lagi pada pemakaian berikutnya.

4. Pembagian data ke pihak ketiga

Kami tidak menjual, menyewakan, atau memperdagangkan data pengguna. Data Google Anda tidak dibagikan kepada pihak ketiga, kecuali bila diwajibkan oleh hukum yang berlaku atau untuk menyelidiki penyalahgunaan. Aplikasi ini tidak memakai jaringan periklanan, data broker, atau pelacak pihak ketiga.

5. Kepatuhan Google API Services User Data Policy

Penggunaan informasi yang diterima aplikasi ini dari Google API mengikuti Google API Services User Data Policy, termasuk persyaratan Limited Use. Secara khusus:

  • Data Google hanya dipakai untuk menyediakan atau meningkatkan fitur yang terlihat jelas di antarmuka aplikasi ini.
  • Data Google tidak ditransfer ke pihak lain kecuali seperlunya untuk menjalankan fitur tersebut, untuk alasan keamanan, atau untuk mematuhi hukum.
  • Manusia tidak membaca data Google Anda, kecuali Anda memberikan persetujuan eksplisit, atau bila diperlukan untuk keamanan/penyalahgunaan, atau bila diwajibkan hukum.
  • Data Google tidak dipakai atau ditransfer untuk periklanan, retargeting, penilaian kredit, atau penjualan data.

6. Data yang kami simpan sendiri (bukan dari Google)

Agar aplikasi bisa berfungsi, kami menyimpan hal berikut di database kami sendiri (Cloudflare D1):

  • Akun: alamat email, hash password (PBKDF2) beserta salt, role akses (admin/registered/read only), dan status aktif.
  • Profil operator: nama, IAA ID, dan LIC No. yang Anda isi sendiri.
  • Data operasional: data penerbangan, NOTAM, TAF, cuaca, waypoint, dan hasil analisis yang dipakai untuk briefing serta jejak audit perubahan.

Data ini dipakai hanya untuk menjalankan fungsi operasional aplikasi, tidak untuk periklanan, dan tidak dijual. Penyimpanan dan pemrosesan dilakukan melalui penyedia infrastruktur kami, yaitu Cloudflare (hosting dan basis data).

7. Retensi dan penghapusan

  • Data operasional dan jejak audit disimpan selama diperlukan untuk keperluan operasional dan keselamatan penerbangan.
  • Anda dapat meminta penghapusan akun dan data profil Anda dengan menghubungi kontak di bawah. Kami akan menindaklanjuti dalam waktu yang wajar.
  • Menghapus akun aplikasi tidak menghapus file Google Sheets yang sudah dibuat di Drive Anda — file itu milik Anda sepenuhnya dan bisa Anda kelola sendiri di Google Drive.

8. Hak Anda dan cara mencabut akses Google

  • Cabut izin aplikasi ini terhadap akun Google Anda kapan saja di myaccount.google.com/permissions. Setelah dicabut, fitur pembuatan Google Sheets tidak akan bisa memakai akun tersebut sampai Anda memberi izin lagi.
  • Anda berhak meminta salinan, koreksi, atau penghapusan data akun dan profil Anda yang kami simpan.
  • Penolakan memberi izin Google tidak menghalangi fitur lain: laporan tetap bisa diunduh sebagai file XLSX tanpa akun Google.

9. Keamanan

Akses ke aplikasi dibatasi oleh akun dan role. Password disimpan dalam bentuk hash (PBKDF2) dengan salt, bukan teks biasa. Komunikasi dengan aplikasi menggunakan HTTPS. Meski demikian, tidak ada sistem yang bisa dijamin sepenuhnya aman; laporkan dugaan masalah keamanan ke kontak di bawah.

10. Perubahan kebijakan

Kebijakan ini dapat diperbarui bila fungsi aplikasi atau kewajiban hukum berubah. Versi terbaru selalu tersedia di halaman ini dengan tanggal pembaruan di bagian atas.

Summary for Google API reviewers

App: AWQ Cloud Briefing (https://christiandaniel.my.id) — a flight dispatch briefing workspace for NOTAM, TAF, weather, FIR and crew briefing reports.

Requested scope: only https://www.googleapis.com/auth/drive.file (non-sensitive). No other Google API scope is requested.

Why the scope is needed: the "Create Google Sheet" action converts the generated crew briefing report into a native Google Sheets file. The file is created in the signed-in user's own Google Drive using that user's own OAuth grant, and the app then opens the file's edit URL. The scope is limited to files this app creates or that the user opens with it; the app cannot list, read, or modify the user's other Drive files.

Token handling: the access token is obtained in the browser through Google Identity Services and is used only for that single upload. It is never stored on the application backend, never written to localStorage, and never sent to our servers.

Data storage: no Google user data (no Drive content, no Google profile data) is stored on our servers. The app's own account and operational data live in Cloudflare D1 and are unrelated to Google APIs.

Limited Use: our use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Google user data is not sold, not transferred to third parties, not used for advertising or retargeting, and is not read by humans except with explicit consent, for security purposes, or as required by law.

Revocation: users can revoke access at myaccount.google.com/permissions at any time. The XLSX download remains available without any Google account.
